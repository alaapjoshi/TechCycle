Estimate a price

Ask what a used part is worth

The price tab takes a plain-text description of a device or part and asks an OpenAI model for resale price ranges by condition.

  • Free-text input, for example "Galaxy S10 screen, cracked"
  • Request goes through a small local Node.js server
  • Results are model estimates, not live market prices
